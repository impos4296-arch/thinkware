제품별 · 일자별 잔여재고 조회

창고 → 브랜드 → 카테고리 → 시리즈 → 제품 순으로 좁혀서 날짜별 재고를 확인하세요

창고·브랜드·카테고리·시리즈·제품은 각 항목을 클릭해 원하는 값을 체크하면 여러 개를 동시에 선택할 수 있습니다(중복 선택 가능). "전체"를 선택하면 개별 선택이 해제됩니다. 제품 목록은 위에서 선택한 브랜드·카테고리·시리즈·구분 조건에 맞는 품목만 표시되며, 검색창에 품목명 일부를 입력해 좁힐 수 있습니다.

2026-08-25

아래 창고별 수량은 현재 선택한 브랜드·카테고리·시리즈·구분 조건에 해당하는 보유재고입니다. 조건이 모두 "전체"이면 창고 전체 재고가 표시됩니다.

UBUS·위니온·세탁기·수입창고 재고는 일자별 데이터가 없어 각 창고/채널의 최신 스냅샷 값으로 고정 표시됩니다(세탁기는 주 2회 갱신). 표시 항목이 이에 해당합니다.

[본품] 품목별 잔여재고 (전체 창고)

[ACC] 품목별 잔여재고

주요 재고 알림

선택한 창고 기준 합계(TM 자체창고·3PL·UBUS만 해당, 수입창고 제외) · B급 재고·리퍼제품·재고 0개 품목은 제외 · 이 알림은 "구분"(본품만/ACC 포함) 설정과 무관하게 항상 본품(완제품) 기준으로만 집계됩니다 · 로봇청소기는 S10·S9·S8만, Stand 청소기는 F25 제외 · 위 브랜드·카테고리·창고 필터 조건 반영(시리즈·제품·구분 필터는 이 알림에는 적용되지 않습니다)

제품별 이번 달 입고 수량

이번 달 누계 입고 수량입니다(조회일자 슬라이더와 무관, 일자별 데이터는 원본 파일에 없어 제공되지 않습니다). TM 자체창고=TM매입+교환반품, 3PL·UBUS·세탁기는 각 창고 파일의 입고 수량 기준(B급/특가 재고 제외). 위니온·수입창고는 입고 데이터가 없어 표시되지 않습니다.

선택 구간 재고 추이 (8/1 – 8/25, 전체 창고 합계)

선택한 조건의 일별 합계 추이 -
수량 단위: 개(EA), 본품 + ACC 합산. 3PL·UBUS 본품 구분은 창고별 출고 실적 기준으로 분류.
